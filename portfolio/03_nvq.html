Complete technical and graphical realisation for this online, multiuser concept created for Factor5 (for "Voetbal International" Netherlands).

Detail

People can be a soccer manager for a football season. They compete to attain a top 10 ranking by playing wisely in the following ways:

  • answering questions in the field of soccer,
  • challenging other online users for a 1-on-1 challenge.

Features

The "Nationale Voetbal Quiz" features the following:

  • 100% Flash interface (see screenshots)
  • Online messaging
  • Online trading
  • A unique client synchronisation mechanism: if anything in a user's state on the server changes, it is automatically pushed to the client.

Results

The "Nationale Voetbal Quiz" delivered:

  • over 20,000 subscriptions
  • periods of 250 to 350 concurrent users online doing messaging and online quizzes, running on a single web server
  • 350,000+ one-on-one quizzes in the first 3 months (100,000+ a month)
  • 750,000+ emails sent in the first 3 months to a 20,000+ user base
