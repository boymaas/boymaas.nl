Hitmaster v2.0

Coca-Cola®, Radio538 and Hitkrant

Second version of online concept. In this game users can be a popmanager. You will have to buy popstars with a budget of one million dollars. To make profit and earn points you will have to buy those stars that will obtain most publicity on radio538 and the Hitkrant. If you get to the top 5, you can start collecting prizes!

Features:

  • 100% flash interface
  • has interaction features unable to achieve using an HTML interface
