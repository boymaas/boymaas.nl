Some highlights of my freelance work

Telfort Order System (Amsterdam, Netherlands)

Complete design and implementation and administration of a web-enabled order handling system. Using web-workflow techniques to streamline Telforts complete orderhandling processes.

Tracker Workflow Information System (Amsterdam, Netherlands)

The complete design and implementation of a robust workflow-handling system to support 1 to 5 level workflows.

Genesis Callcentre(UK) Workflow and Knowledge Management System, (Manchester, United Kingdom)

Providing a fast growing callcentre with an IT implementation plan. Follow-up work includes the creation of a knowledge-management system, workflow and database management tools, as well as template-generation engine and bulletinboard system.

Telfort Versatility Launch (Amsterdam, Netherlands)

Creation of a bulletin board / Q&A system for the Telfort bv mobile callcentre to support the launch of the mobile network in 1998. This contained an advanced end-user administration module and templatised display of news for customer service representatives. This was designed to run within Telfort's Versatility workflow and scripting system.
